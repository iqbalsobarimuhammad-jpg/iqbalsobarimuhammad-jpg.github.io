Kebijakan Privasi

Berlaku sejak 10 November 2026 · Kantor Konten

Siapa yang memakai aplikasi ini

Kantor Konten adalah alat pribadi. Satu-satunya pengguna adalah pemiliknya, Iqbal Sobari, yang menghubungkan channel YouTube miliknya sendiri.

Data yang diakses

  • Izin unggah YouTube (youtube.upload): untuk mengunggah video buatan pemilik ke channel pemilik, termasuk judul, deskripsi, tag, dan jadwal tayang.
  • Izin baca akun YouTube (youtube.readonly): hanya untuk menampilkan nama channel yang terhubung dan memeriksa status video yang diunggah.

Aplikasi tidak membaca komentar, pesan, data penonton, atau data akun Google lainnya.

Penyimpanan dan berbagi data

Token akses Google disimpan hanya di komputer pemilik dan tidak dikirim ke server mana pun selain layanan Google sendiri. Data tidak dijual, tidak dibagikan, dan tidak dipakai untuk iklan atau pelatihan model.

Penggunaan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Akses bisa dicabut kapan saja lewat myaccount.google.com/permissions. Setelah dicabut, token di komputer pemilik tidak bisa dipakai lagi dan bisa dihapus.

English summary

Kantor Konten is a single-user personal tool. It uses the YouTube upload scope to upload the owner's videos to the owner's own channel, and the read-only scope to show the connected channel name and check upload status. Tokens are stored only on the owner's computer, are never shared or sold, and use of Google API data follows the Google API Services User Data Policy, including Limited Use. Access can be revoked at myaccount.google.com/permissions.
